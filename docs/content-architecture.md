# Content architecture

A Cloud Secure Edge information architecture (IA) restructure, and an estate-wide IA model for evaluating doc sets in a single-pane view.

- **[CSE documentation IA rework](./docs-engineering/cse-ia-rework-case-study.mdx):** the sidebar was grouped by product component, and was regrouped around reader tasks. The change was made in the navigation layer only: no page file moved and no published URL changed.
- **[Information architecture for a product estate](./docs-engineering/ia-model-case-study.mdx):** documentation across a multi-product portfolio had grown up per product, in incompatible source systems, with no shared definition of a complete doc set. The model puts every product on one axis, with statuses decided by rule and counts taken from navigation data.

The first covers the navigation of one product. The second covers how products are compared against each other.
