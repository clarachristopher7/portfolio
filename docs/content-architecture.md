# Content architecture

Cloud Secure Edge information architecture (IA) restructure, and an estate-wide IA model built to evaluate doc sets in a single-pane view.

- **[CSE documentation IA rework](./docs-engineering/cse-ia-rework-case-study.mdx):** a sidebar organized around the product's components, regrouped around what a reader arrives wanting to do. Done entirely in the navigation layer: no page file moved and no published URL changed.
- **[Information architecture for a product estate](./docs-engineering/ia-model-case-study.mdx):** documentation that grew up per product, in incompatible source systems, with no shared definition of a complete doc set. An instrument that puts the whole estate on one axis, with statuses decided by rule and counts derived from navigation data rather than estimated.

One is a single product's navigation; the other is the model for comparing products that were never built to be compared.
