# Admin console homepage

<p className="hub-sub">The admin console's homepage filled the screen with graphs, but the numbers in them didn't tell admins anything they could act on. The product designer and I redesigned it around the reasons that customers buy Cloud Secure Edge.</p>

<div className="ctx-prose">
  <p className="ctx-label">Background</p>
  <p>Cloud Secure Edge is a SonicWall service that decides whether an employee's device can connect to company apps and websites. Admins set it up and run it from a web-based admin console.</p>
  <p>The homepage is the first screen that an admin sees after they sign in. It's the natural place to answer one question: is Cloud Secure Edge doing the job that we bought it for?</p>
  <p>Customers buy Cloud Secure Edge for a small set of primary use cases. I worked on the redesign with the product designer. My part was to choose the metrics that show how each of those use cases is going.</p>
</div>
