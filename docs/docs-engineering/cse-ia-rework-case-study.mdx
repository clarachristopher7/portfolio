# Cloud Secure Edge information architecture

<p className="hub-sub">I restructured the Cloud Secure Edge documentation around the tasks readers come to complete. The new structure is live, and every existing link still works.</p>

<dl className="ctx">
  <div><dt>The product</dt><dd>The documentation site for Cloud Secure Edge, a SonicWall security service that controls which employees and devices can reach company applications and websites.</dd></div>
  <div><dt>Who uses it</dt><dd>Administrators evaluating, setting up, and running the product, and those diagnosing problems under time pressure.</dd></div>
  <div><dt>What they’re doing</dt><dd>Finding the page for the job at hand. The navigation mirrored how the product is engineered, so readers needed to understand its internal components before they could find out how to use it.</dd></div>
  <div><dt>My part</dt><dd>I designed the new structure, rewrote the navigation labels, and redesigned the documentation homepage.</dd></div>
</dl>
