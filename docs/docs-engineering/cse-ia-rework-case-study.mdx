# CSE documentation IA rework

The Cloud Secure Edge sidebar was organized around the product's components, one group per piece of the platform. That follows how the product is built, not what a reader arrives wanting to do. I regrouped it around tasks, in the order a customer does them: learn, activate, deploy, set up users and devices, write policies, secure resources, monitor, troubleshoot. The restructure is live on the Cloud Secure Edge docsite. No published URL changed.

## In brief

**Problem.** The sidebar was organized around the product's components, one group per piece of the
platform. That grouping follows the product's build structure, while readers arrive wanting to do a task.

**Constraint.** Regroup freely in the navigation layer; break nothing a reader had bookmarked. No page
file could move and no published URL could change, which ruled out any fix that involved relocating
content rather than relabelling and regrouping it.

**What I tried.** [What you considered and rejected before landing on a nav-layer-only change. Did you
scope a version that moved files and cost redirects? Was there a task taxonomy you drafted and dropped?]

**What I shipped.** A sidebar grouped by reader task. Four new bands: Deploy, Set Up Users and Devices,
Monitor and Maintain, and Troubleshooting. Platform Components split into concepts and tasks. Manage Users
and Devices broken into five setup groups. 27 integration guides that weren't in the sidebar are now listed
under Solution Guides. 19 new pages, mostly landing pages for the new groups.

**What changed.** Top-level groups 26 → 34, bands 7 → 10, sidebar entries 278 → 319, with zero URLs
changed. [Add what it did for readers: a search or support signal, or feedback from the field.]

## Before and after

![The Cloud Secure Edge docs sidebar before and after the restructure, side by side. Before: 26 top-level groups in 7 bands. After: 34 top-level groups in 10 bands, with new Deploy, Set Up Users and Devices, Monitor and Maintain, and Troubleshooting bands.](/img/content-architecture/cse-sidebar-before-after.png)

The new bands follow the order a customer actually works in. Before, a reader who wanted to install a Connector had to know that it lived under Platform Components. Now there is a group called Install a Connector.
