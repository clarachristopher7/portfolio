# Reorganizing security docs around tasks

<p className="hub-sub">These security docs were organized the way engineers built the product. But admins don't show up thinking in components. They show up with a task. I reorganized the docs around those tasks, and every existing link still works.</p>

<div className="ctx-prose">
  <p className="ctx-label">Background</p>
  <p>Cloud Secure Edge is a service that decides whether an employee's device can connect to company apps and websites.</p>
</div>
