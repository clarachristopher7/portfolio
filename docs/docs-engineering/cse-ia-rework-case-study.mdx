# Cloud Secure Edge information architecture

<p className="hub-sub">I reorganized the Cloud Secure Edge docs around the tasks that admins come to do. The new structure is live, and every existing link still works.</p>

<div className="ctx-prose">
  <p className="ctx-label">Background</p>
  <p>Cloud Secure Edge is a service that decides whether an employee's device can connect to company apps and websites.</p>
</div>


<div className="chain brief-flow">
  <div className="arch-node arch-node--old"><b>The problem</b><span>The navigation was organized by product component. Admins come to the docs with a task.</span></div>
  <div className="arch-node"><b>The approach</b><span>I kept every page where it was and changed only the navigation: new section names, a new section order, and a homepage organized by goal.</span></div>
  <div className="arch-node"><b>The constraint</b><span>I could change only the navigation. No page could move and no URL could change. Bookmarks, search results, and links from support articles all had to keep working.</span></div>
  <div className="arch-node arch-node--new"><b>The outcome</b><span>Each task now has a name that describes the work, in the order that an admin does it. In the first quarter after launch, support cases about finding a doc dropped by about a third.</span></div>
</div>
