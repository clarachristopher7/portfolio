# CSE Documentation IA Rework

The Cloud Secure Edge sidebar was organized around the product's components — one group per piece of the platform — which mirrors how the product is built rather than what a reader arrives wanting to do. The restructure regrouped it around tasks. It happened entirely in the navigation layer: no page file moved, and no published URL changed.

<p className="case-label case-label--close">What this demonstrates</p>

Reorganising around the reader's task rather than the product's build structure — and doing it in the navigation layer alone, so that 311 nav entries could be rearranged without dropping a page, duplicating an entry, or breaking a single published URL.
