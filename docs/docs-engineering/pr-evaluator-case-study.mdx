# PR-to-docs impact evaluator

<p className="hub-sub">A scheduled job that lists the docs pages a recent product change made out of date. It reports. A person decides.</p>

## How it works

<ol className="ia-steps ia-steps--4" aria-label="How the evaluator works">
  <li>Read recent merges</li>
  <li className="is-new">Check what's actually live<small>Key step</small></li>
  <li>Compare against every docs page</li>
  <li>Write a report</li>
</ol>

## What made it work

<HubGroup columns={2}>
  <HubCard icon="git" tag="Lesson" title="Read the right branch">
    An early version read a QA branch and missed most changes. Features land on dev first.
  </HubCard>
  <HubCard icon="search" tag="Lesson" title="Merged isn't live">
    It looks for each change in the code customers are served, so the docs match what they can see.
  </HubCard>
</HubGroup>
