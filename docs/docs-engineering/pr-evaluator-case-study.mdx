# Docs change checker

<p className="hub-sub">An automatic daily check that lists the help pages a recent product change made out of date. It only reports. A person decides what to fix.</p>

## How it works

<ol className="ia-steps ia-steps--4" aria-label="How the evaluator works">
  <li>Read recent product changes</li>
  <li className="is-new">Check what customers can see<small>Key step</small></li>
  <li>Compare with every help page</li>
  <li>Write a report</li>
</ol>

## What made it work

<HubGroup columns={2}>
  <HubCard icon="git" tag="Lesson" title="Watch the right place">
    An early version watched a testing copy of the code and missed most changes. New work shows up somewhere else first.
  </HubCard>
  <HubCard icon="search" tag="Lesson" title="Finished isn't released">
    It checks whether each change has actually reached customers, so the docs match what they see.
  </HubCard>
</HubGroup>
