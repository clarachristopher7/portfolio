# Docs change checker

<p className="hub-sub">An automatic daily check that lists the help pages a recent product change made out of date. It only reports. A person decides what to fix.</p>

<dl className="ctx">
  <div><dt>The situation</dt><dd>Engineers change the product every week. A help page goes out of date the moment a change it describes ships, and nobody tells the docs team.</dd></div>
  <div><dt>Who uses it</dt><dd>The docs team.</dd></div>
  <div><dt>What it does</dt><dd>Every day it reads what engineers changed, checks which changes customers can actually see, and uses AI to compare each one against every help page. Then it lists the pages that look out of date.</dd></div>
  <div><dt>My part</dt><dd>I designed and built it.</dd></div>
</dl>


## How it works

<ol className="ia-steps ia-steps--4" aria-label="How the evaluator works">
  <li>Read recent product changes</li>
  <li className="is-new">Check what customers can see<small>Key step</small></li>
  <li>Compare with every help page</li>
  <li>Write a report</li>
</ol>

## What made it work

<HubGroup columns={2}>
  <HubCard icon="git" tag="Lesson" title="Watch the right place">

  </HubCard>
  <HubCard icon="search" tag="Lesson" title="Finished isn't released">
