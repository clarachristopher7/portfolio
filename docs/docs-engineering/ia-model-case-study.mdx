# Information architecture across a product portfolio

<p className="hub-sub">Each SonicWall product's docs grew separately. I built a model that measures every product's docs against one definition of complete, so each gap comes with evidence.</p>

<div className="ctx-prose">
  <p className="ctx-label">Background</p>
  <p>SonicWall sells firewalls, cloud services, apps for employees' computers, and portals for partner companies. A different team wrote each product's docs, in a different tool. No one had agreed on what a complete set of docs contains.</p>
  <p>Without that agreement, docs leads and product owners could not see where the gaps were or decide where to spend effort. I designed the model, the rules that set each status, and a single-page tool that shows the results.</p>
</div>

## Fair comparisons across product types

A cloud service and a hardware appliance need different docs. So each product has a type, and only the sections that apply to that type count. A status then means the same thing on every product.

<p className="ia-chips"><span>Cloud service</span><span>Hardware appliance</span><span>Employee app</span><span>Partner portal</span><span>Shared content</span></p>
