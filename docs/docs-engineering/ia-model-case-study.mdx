## Fair to unlike products

A cloud service and a hardware appliance need different docs. Each product type gets only the sections that fit it, so one score means the same thing everywhere.

<p className="ia-chips"><span>Cloud service</span><span>Appliance</span><span>End-user app</span><span>Partner console</span><span>Shared content</span></p>
