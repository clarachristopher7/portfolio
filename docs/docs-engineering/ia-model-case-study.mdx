# Organizing docs across many products

<p className="hub-sub">Each product's help docs had grown up separately. I built one map that checks them all against the same idea of complete.</p>

<div className="ia-brief">
  <div><h4>Problem</h4><p>There was no way to compare products, so gaps were argued about instead of shown.</p></div>
  <div><h4>Constraint</h4><p>One simple file that anyone can open and any writer can update.</p></div>
  <div><h4>What I tried</h4><p>[An approach you considered and dropped.]</p></div>
  <div><h4>The outcome</h4><p>[Add a result.]</p></div>
</div>

## One map, three views

  <HubCard icon="layers" tag="Sections" title="Where a page lives">

## Fair to unlike products

A cloud service and a hardware device need different docs. Each type of product is only checked for the sections that fit it, so the results are fair.

<p className="ia-chips"><span>Cloud service</span><span>Appliance</span><span>End-user app</span><span>Partner portal</span><span>Shared content</span></p>
