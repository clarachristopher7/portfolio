# Documentation staleness auditor

<p className="hub-sub">Compares the docs with each new version of the admin console and produces a maintenance backlog, sorted so the biggest gaps get fixed first.</p>

<div className="ctx-prose">
  <p className="ctx-label">Background</p>
  <p>The admin console ships new versions regularly. Each release can change field labels, screenshots, and steps across many pages at once, and periodic manual review usually catches those changes after customers do.</p>
  <p>I designed and built an auditor that compares every page with the current console, flags the pages that no longer match it, and ranks them into a backlog by impact.</p>
</div>
