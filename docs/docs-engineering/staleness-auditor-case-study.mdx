# Outdated page finder

<p className="hub-sub">Checks every help page against the latest version of the product and ranks what to fix first.</p>

<dl className="ctx">
  <div><dt>The situation</dt><dd>When a new version of the product’s admin screens ships, many help pages can go out of date at once. Checking hundreds of pages by hand doesn’t scale.</dd></div>
  <div><dt>Who uses it</dt><dd>The docs team.</dd></div>
  <div><dt>What it does</dt><dd>Compares every help page with the new version, then ranks the pages by how outdated they are and how often people read them, so the most important fixes come first.</dd></div>
  <div><dt>My part</dt><dd>I designed and built it.</dd></div>
</dl>
