# Documentation staleness auditor

<p className="hub-sub">Checks the docs against each new version of the admin console and gives you a maintenance backlog, sorted so the biggest gaps get fixed first.</p>

<dl className="ctx">
  <div><dt>The situation</dt><dd>The admin console ships new versions regularly, and each release can quietly invalidate field labels, screenshots, and procedures across a large set of docs. Periodic manual review tends to find those changes after customers do.</dd></div>
  <div><dt>Who uses it</dt><dd>The docs team.</dd></div>
  <div><dt>What it does</dt><dd>It compares every page with the current console, flags where a page no longer matches the interface, and ranks what it finds into a backlog by impact.</dd></div>
  <div><dt>My part</dt><dd>I designed and built it.</dd></div>
</dl>

## How it works
