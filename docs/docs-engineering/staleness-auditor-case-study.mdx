# Documentation staleness auditor

<p className="hub-sub">Cross-references the documentation against each new version of the admin console and produces a prioritized maintenance backlog, so effort goes to the highest-impact gaps first.</p>

<dl className="ctx">
  <div><dt>The situation</dt><dd>The admin console ships new interface versions regularly. Each release can invalidate field labels, screenshots, and procedures across a large documentation set, faster than periodic manual review can detect.</dd></div>
  <div><dt>Who uses it</dt><dd>The documentation team.</dd></div>
  <div><dt>What it does</dt><dd>Compares every page with the current console, identifies where pages no longer match the interface, and orders the findings into a backlog ranked by impact.</dd></div>
  <div><dt>My part</dt><dd>I designed and built it.</dd></div>
</dl>
