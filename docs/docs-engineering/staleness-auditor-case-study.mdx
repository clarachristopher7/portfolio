# Documentation staleness auditor

<p className="hub-sub">The auditor compares the docs with each new version of the admin console. It produces a maintenance backlog in order of impact, so the team fixes the largest gaps first.</p>

<div className="ctx-prose">
  <p className="ctx-label">Background</p>
  <p>SonicWall releases new versions of the admin console often. A release can change field labels, screenshots, and steps on many docs pages at the same time. Manual reviews usually find those changes after customers find them.</p>
  <p>I designed and built an auditor that compares every docs page with the current console. It flags each page that no longer matches the console and ranks the flagged pages by impact.</p>
</div>
