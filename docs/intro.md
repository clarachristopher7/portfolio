# Start here

I'm Clara Christopher, a content architect for cloud security products. I design how the
product UI and docs are written, structured, and published, considering everything from
the user journey to how the docs pipeline is built.

At SonicWall I own the Cloud Secure Edge content end to end. I work with designers and
front-end engineers to build in-product experiences, and I'm currently rearchitecting
SonicWall's hardware and cloud product publishing flow. My background also includes
Tailscale, Banyan Security, Quantum XChange, and Security Compass.

This section is a self-contained sample of my work — no logins, no links to docs I no
longer maintain.

## What's here

- **Product & conceptual docs** — the kind of end-user-facing, explain-the-concept-before-the-steps writing that makes up most of my track record.
- **Content design** — in-product strings, error states, and the information architecture around them: the writing that lives inside the interface, where a reader is mid-task and every word is load-bearing.
- **API reference & code samples** — reference documentation paired with a tested code sample, to show the mechanical/developer-docs side of the craft.
- **Docs engineering case studies** — projects where I treated documentation as infrastructure: automation, CI/CD, and tooling that keeps docs correct instead of just polished once and left to rot.

Each sample includes a short "why this one" note explaining what it's meant to demonstrate.
