# About me

Content architect for cloud security products. I design how the product UI and docs are
written, structured, and published, considering everything from the user journey to how
the docs pipeline is built.

At SonicWall I own the Cloud Secure Edge content end to end. I work with designers and
front-end engineers to build in-product experiences, and I'm currently rearchitecting
SonicWall's hardware and cloud product publishing flow.

## What's here

- **Docs:** live pages I write and maintain on the SonicWall Cloud Secure Edge docs site.
- **Content architecture:** Cloud Secure Edge information architecture (IA) restructure, and an estate-wide IA model built to evaluate doc sets in a single-pane view.
- **Content design:** in-product strings, their structuring, and their sequencing.
- **Automations:** projects where I used AI-assisted analysis and tooling to keep docs current and robust.
